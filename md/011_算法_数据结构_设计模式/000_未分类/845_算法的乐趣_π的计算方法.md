### 古代埃及

![图片描述](https://doc.shiyanlou.com/courses/uid1190679-20220818-1660792421360)

- 埃及人似乎更早的知道圆周率
- 造于公元前2500年左右的胡夫金字塔和圆周率有关
- 金字塔的周长和高度之比等于圆周率的两倍
- 正好等于圆的周长和半径之比
- 据说算法是16/9的平方（近似为3.1604)

### 古希腊(几何法)

- 公元前250年左右
- 古希腊著名数学家阿基米德抛弃了原有的方法去测定圆周

![图片描述](https://doc.shiyanlou.com/courses/uid1190679-20220818-1660792913675)

- 开创性地采用几何法测定圆周率
- 勾股定理已经成型
- 各类作图工具都有了质的提升
- 阿基米德才用割圆法
- 将一个圆近似看成6边形
	- 圆的周长在内外结六边形之间
	- 再12边形...再24切割...用96边形
		- 计算出圆周率的数值在223/71和22/7之间

![图片描述](https://doc.shiyanlou.com/courses/uid1190679-20220818-1660800803947)

- 远古时代微积分的感觉
- 阿基米德取其平均数为3.14

- 如果半径是1
- 红加绿的面积就是π

### 莱布尼茨公式

### 编码

```python
i = 1
pi = 0
bound = 100
while i<bound:
    pi += 4 * ((-1)**(i+1)/(2*i-1))
    i = i + 1
print(pi)
```

- 如果循环 100 次的话
- 结果是

![图片描述](https://doc.shiyanlou.com/courses/uid1190679-20211215-1639547390535)

- 显然精度达不到要求

### 精度

```python
i = 1
pi = 0
bound = 100000000
while i<bound:
    pi += 4 * ((-1)**(i+1)/(2*i-1))
    i = i + 1
print(pi)
```

- 提高 bound 的值之后
- 计算时间增加了
- 精度也有提高
