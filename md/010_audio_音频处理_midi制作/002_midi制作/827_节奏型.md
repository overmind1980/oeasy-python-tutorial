
- 创建鼓和bass的节奏型
	- bass频率上对齐旋律
	- 节奏上对齐鼓

```
# 丰富节奏模式
rhythms = [
    [1, 0, 1, 0, 1, 0, 1, 0],  # 八分音符
    [2, 0, 2, 0, 2, 0, 2, 0],  # 四分音符
    [1, 1, 1, 1, 1, 1, 1, 1],  # 十六分音符
    [3, 0, 3, 0, 3, 0, 3, 0],  # 附点八分音符
    [1, 3, 1, 3, 1, 3, 1, 3],  # 切分节奏
    [1, 1, 3, 1, 1, 3, 1, 1],  # 新的复杂节奏
    [2, 2, 1, 1, 2, 2, 1, 1]  # 另一种节奏
]

```
