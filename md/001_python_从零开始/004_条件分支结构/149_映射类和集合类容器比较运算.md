### 大于小于

```
{1, 2} < {1, 2, 3}
{1, 2} > {1, 2, 3}
```

- 如果有 从属子集关系的话
  - 超集 大于 子集
  - 子集 小于 超集

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/203075/uid1190679-20260331-1774940430319) 

- 大于/小于 
	- 必须是 真子集/真超集

### 大于等于

- 一般的 子集/超集对应 
	- 大于等于
	- 小于等于

```

{1, 2} >= {1, 2}
```

- {1, 2} 不是 {1, 2}的 真超集

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/203075/uid1190679-20260331-1774940506487)

### 总结

- 这次研究了比较
  - 映射类 map
    - dict 字典
  - 集合类
    - set
    - frozenset

| 比较运算符 | 字典 (dict) | 集合 (set) |
|------------|-------------|------------|
| `==` | 键值对**完全相同**则为 True<br>顺序不影响 | 元素**完全相同**则为 True<br>顺序不影响 |
| `!=` | 键/值有任一不同 <br>True | 元素有任一不同 <br>True |
| `<、<=、>、>=` | ❌ **直接报错**<br>字典不支持大小比较 | ✅ **支持**<br>表示**子集/超集**关系 |

- 比较运算符还有
  - 对称性
  - 传递性
- COMPARISON 中还有个 
	- 成员测试
	- Membership test
