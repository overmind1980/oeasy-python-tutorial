### zip

- zip 可以缝合
	- 序列类

```
stu = ["oeasy", "o2z", "o3z"]
math = [95, 96, 97]
score = list(zip(stu, math))
score
```

- zip 把 若干个列表
	- 按位置组合 缝合 成 新容器
	- 新容器 可以理解成一个列表

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/1025664/uid1190679-20260512-1778571558330)

### 音译汉、汉译英

- 字典里 键肯定是唯一的
	- 如果值 也是唯一的
	- 键值(key-value) 可以对调
	- 依然是一对一的
	- key-value pair

```
han = ["猫", "狗", "鼠"]
eng = ["cat", "dog", "rat"]
h2e = dict(zip(han, eng))
h2e
e2h = dict(zip(eng, han))
e2h
```

- 英译汉
	- 倒过来
		- 就是汉译英
