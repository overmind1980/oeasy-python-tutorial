### 字典解包融合

- **d1 是 字典d1解包
	- **d2 是 字典d2解包

```python
d1 = {"a": 1}
d2 = {"b": 2}
merge_dict = {**d1, **d2}
```

- 把两个 解包后的字典 
	- 组合成 新字典merge_dict
	- d1、d2都没有改变

### 快速写法

```python
d1 = {"a": 1, "b": 2}
d2 = {"a": 2, "c": 3}
merge_dict = {**d1, **d2}
merge_dict
d1
d2
```

- 新字典 生成
	- 老字典 不受影响
