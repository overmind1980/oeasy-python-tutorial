### 修改为步骤为核心

- 结构本身 就有 明确的意义

```
生成 Python 字典 food_dict，结构：菜品名→步骤 1 / 步骤 2→单步字典。单步可选键：材料 (列表、带用量)、调味料 (列表、带用量)、烹饪方法；无内容就删掉对应键。内容做番茄炒蛋、宫保鸡丁，步骤描述详细。
```

### 细化

```
生成 Python 字典 food_dict，结构：菜品名→步骤 1 / 步骤 2→单步字典。单步可选键：材料 (列表、带用量)、调味料 (列表、带用量)、烹饪方法；无内容就删掉对应键。内容做番茄炒蛋、宫保鸡丁，步骤描述详细。每一步有一个key是产出结果。材料和调味料要有具体的量，烹饪方法要有具体火候和时间。每步只做一件事情。
```
