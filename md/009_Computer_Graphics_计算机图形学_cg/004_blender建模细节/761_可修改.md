- 为什么 字典前面 
	- 使用的是 元组呢？

### 询问ai

- 按照这个思路 把列表  转化为 元组

### 元组

```
tpl = tuple(list(range(5)))
print(tpl)
dic = {tpl : "range5"}
dic
```

- 执行成功

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/4113121/uid1190679-20250717-1752724872998) 

- 如果是变量作为key 
	- 也是不可哈希的
	- 不满足 值不可变的 

### 实验

```
var = 3
dic = {var: "three"}
dic
```

- 可以用变量var 对 dic中的key 赋值

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/4113121/uid1190679-20250717-1752725045927) 

- 如果此时 修改var呢？

### 修改

```
var = 4
dic
```

- 将var修改为4
	- 但是 dic 不受影响

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/4113121/uid1190679-20250717-1752725549387) 

- 在构造字典的过程中
	- 就已经把key从一个变量
	- 变成了 一个可以哈希的 固定值
- 为什么会把key固化？

### 原因分析

![图片描述](https://doc.shiyanlou.com/courses/3584/labs/4113121/uid1190679-20250717-1752726161166) 

- 字典的优点就是 
	- 根据key
	- 快速得到 value
- 如果key都不稳定
	- 没法保证 查找过程顺畅 


### 总结

- 这次了解到 字典的特性
	- 字典中的 key 必须是 
		- 可以 哈希的 
		- 一个 固定值
- ai 还能 如何 帮我们编程呢？
